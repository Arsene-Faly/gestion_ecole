## Validations de l'année scolaire

✓ Nom obligatoire
✓ Format 2026-2027
✓ Années consécutives
✓ Date de début obligatoire
✓ Date de fin obligatoire
✓ Date début < date fin
✓ Correspondance année/date
✓ Nom unique
✓ Une seule année active
✓ Pas de chevauchement
